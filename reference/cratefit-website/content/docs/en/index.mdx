## Introduction

CrateFit is an open-source 3D bin packing library designed for logistics optimization. It helps you solve complex packing problems like:

- **Container loading** - Maximize cargo container utilization
- **Pallet packing** - Build stable, efficient pallets
- **E-commerce shipping** - Select optimal box sizes for orders
- **Truck loading** - Plan efficient delivery routes

## Features

- Multiple packing algorithms (Extreme Point, Layer Building, EB-AFIT)
- Full constraint support (weight, stacking, rotation)
- Real-time 3D visualization
- TypeScript native with full type definitions
- Zero runtime dependencies

## Quick Example

```typescript
import { pack } from '@cratefit/pack';

const result = pack({
  bins: [
    { id: 'box-1', type: 'box', width: 100, height: 100, depth: 100 }
  ],
  items: [
    { id: 'item-1', width: 50, height: 30, depth: 40 },
    { id: 'item-2', width: 30, height: 40, depth: 30 }
  ]
});

console.log(`Packed ${result.stats.packedItems} items`);
console.log(`Utilization: ${(result.stats.avgUtilization * 100).toFixed(1)}%`);
```
