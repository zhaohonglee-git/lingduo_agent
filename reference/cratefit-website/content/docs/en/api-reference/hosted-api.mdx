## Overview

CrateFit provides a public REST API for quick integration. No server setup required.

**Base URL:** `https://cratefit.vercel.app/api`

> **Note:** This API is intended for testing and demonstration purposes only. Endpoints may change without notice. For production workloads, we recommend self-hosting.

## Rate Limits

- 60 requests per minute

Rate limit headers are included in every response:
- `X-RateLimit-Remaining`: Requests remaining in current window
- `X-RateLimit-Reset`: Unix timestamp when the limit resets

## Endpoints

### POST /api/pack

Batch pack items into bins.

**Request:**

```json
{
  "bins": [
    {
      "id": "container-1",
      "type": "box",
      "width": 100,
      "height": 100,
      "depth": 100
    }
  ],
  "items": [
    { "id": "item-1", "width": 50, "height": 30, "depth": 40 },
    { "id": "item-2", "width": 30, "height": 40, "depth": 30 }
  ],
  "options": {
    "algorithm": "extreme-point"
  }
}
```

**Response:**

```json
{
  "packed": [...],
  "unpacked": [...],
  "stats": {
    "packedItems": 2,
    "unpackedItems": 0,
    "totalBins": 1,
    "avgUtilization": 0.45
  }
}
```

### POST /api/pack/online/start

Start an online packing session.

**Request:**

```json
{
  "bin": {
    "id": "container-1",
    "type": "box",
    "width": 100,
    "height": 100,
    "depth": 100
  }
}
```

**Response:**

```json
{
  "sessionId": "session_1234567890_abc123",
  "bin": {...},
  "items": [],
  "utilization": 0
}
```

### POST /api/pack/online/place

Place an item in an active session.

**Request:**

```json
{
  "sessionId": "session_1234567890_abc123",
  "item": {
    "id": "item-1",
    "width": 50,
    "height": 30,
    "depth": 40
  }
}
```

**Response:**

```json
{
  "placed": true,
  "placement": {
    "position": { "x": 0, "y": 0, "z": 0 },
    "rotation": 0
  },
  "items": [...],
  "utilization": 0.06
}
```

### GET /api/pack/online/state

Get current session state.

**Query Parameters:**
- `sessionId` (required): Session ID

**Response:**

```json
{
  "bin": {...},
  "items": [...],
  "utilization": 0.06,
  "remainingCapacity": {...}
}
```

### POST /api/pack/online/reset

Reset a session (clear all placed items).

**Request:**

```json
{
  "sessionId": "session_1234567890_abc123"
}
```

### GET /api/health

Health check endpoint.

**Response:**

```json
{
  "status": "ok",
  "timestamp": "2024-01-01T00:00:00.000Z",
  "version": "0.1.0"
}
```

## Error Responses

All errors follow this format:

```json
{
  "error": "Error message"
}
```

Common status codes:
- `400` - Bad request (invalid input)
- `404` - Session not found
- `429` - Rate limit exceeded
- `500` - Internal server error
