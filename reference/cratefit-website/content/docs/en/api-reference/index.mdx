## Core Functions

### pack()

The main packing function that solves bin packing problems.

```typescript
function pack(config: PackConfig): PackResult
```

**Parameters:**

| Name | Type | Description |
|------|------|-------------|
| `config.bins` | `BinSpec[]` | Available containers |
| `config.items` | `ItemSpec[]` | Items to pack |
| `config.options` | `PackOptions` | Packing options (optional) |

**Returns:** `PackResult` containing packed bins, unpacked items, and statistics.

### Scenario-Specific Functions

- `packPallet()` - Optimized for pallet loading
- `packContainer()` - Optimized for shipping containers
- `packTruck()` - Optimized for truck loading with axle weights
