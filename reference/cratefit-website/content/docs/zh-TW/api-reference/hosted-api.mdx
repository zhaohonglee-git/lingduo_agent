## 概述

CrateFit 提供公開的 REST API，方便快速整合。無需架設伺服器。

**Base URL:** `https://cratefit.vercel.app/api`

> **注意：** 此 API 僅供測試和示範用途。端點可能會在不另行通知的情況下變更。生產環境建議自行架設。

## 速率限制

- 每分鐘 60 次請求

每個回應都會包含速率限制標頭：
- `X-RateLimit-Remaining`：目前時間窗口內剩餘的請求數
- `X-RateLimit-Reset`：限制重置的 Unix 時間戳

## 端點

### POST /api/pack

批次將物品裝入容器。

**請求：**

```json
{
  "bins": [
    {
      "id": "container-1",
      "type": "box",
      "width": 100,
      "height": 100,
      "depth": 100
    }
  ],
  "items": [
    { "id": "item-1", "width": 50, "height": 30, "depth": 40 },
    { "id": "item-2", "width": 30, "height": 40, "depth": 30 }
  ],
  "options": {
    "algorithm": "extreme-point"
  }
}
```

**回應：**

```json
{
  "packed": [...],
  "unpacked": [...],
  "stats": {
    "packedItems": 2,
    "unpackedItems": 0,
    "totalBins": 1,
    "avgUtilization": 0.45
  }
}
```

### POST /api/pack/online/start

開始線上裝箱工作階段。

**請求：**

```json
{
  "bin": {
    "id": "container-1",
    "type": "box",
    "width": 100,
    "height": 100,
    "depth": 100
  }
}
```

**回應：**

```json
{
  "sessionId": "session_1234567890_abc123",
  "bin": {...},
  "items": [],
  "utilization": 0
}
```

### POST /api/pack/online/place

在進行中的工作階段放置物品。

**請求：**

```json
{
  "sessionId": "session_1234567890_abc123",
  "item": {
    "id": "item-1",
    "width": 50,
    "height": 30,
    "depth": 40
  }
}
```

**回應：**

```json
{
  "placed": true,
  "placement": {
    "position": { "x": 0, "y": 0, "z": 0 },
    "rotation": 0
  },
  "items": [...],
  "utilization": 0.06
}
```

### GET /api/pack/online/state

取得目前工作階段狀態。

**查詢參數：**
- `sessionId`（必填）：工作階段 ID

**回應：**

```json
{
  "bin": {...},
  "items": [...],
  "utilization": 0.06,
  "remainingCapacity": {...}
}
```

### POST /api/pack/online/reset

重置工作階段（清除所有已放置的物品）。

**請求：**

```json
{
  "sessionId": "session_1234567890_abc123"
}
```

### GET /api/health

健康檢查端點。

**回應：**

```json
{
  "status": "ok",
  "timestamp": "2024-01-01T00:00:00.000Z",
  "version": "0.1.0"
}
```

## 錯誤回應

所有錯誤遵循此格式：

```json
{
  "error": "錯誤訊息"
}
```

常見狀態碼：
- `400` - 錯誤的請求（無效輸入）
- `404` - 找不到工作階段
- `429` - 超過速率限制
- `500` - 內部伺服器錯誤
